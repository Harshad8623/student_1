# Student Management — PHP/MySQL Prototype

A PHP-based student and teacher web application with admin modules, SQL schema, login flows, and static assets.

## Getting started

Import `database.sql` into a local MySQL database, configure `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` as environment variables, and use a configured PHP web server. Review security before using real personal data.
